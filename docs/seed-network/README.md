# Public Seed Network

These seven repos can be used independently. The arrows show practical ways to share colors, files, or workflow patterns.

| From | To | What you can share |
| --- | --- | --- |
| Syn Themes | Theme Designer, PDF Designer | Editor palette inspiration |
| Theme Designer | PDF Designer | Light and dark brand palette JSON |
| Theme Designer | Dashboard, Bot Seed | CSS colors or a Discord embed accent |
| Voice Seed | PDF Designer, Agency | Writing registers |
| Dashboard | Agency | An optional workspace landing page |
| Agency | Bot Seed | Review and operator workflow patterns |

After cloning this repository, open [index.html](index.html) in a browser for the interactive map. Select any node to see its connections and repository link. Theme Designer ships the same viewer alongside its palette demo.

The viewer owns the public graph and appearance. The light and dark README images are renders of its desktop diagram with no project selected.
